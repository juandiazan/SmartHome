Proyecto desarrollado como entrega para Diseño de Aplicaciones II en Universidad ORT, segundo semestre de 2024. Consiste en una aplicación web desarrollada en ASP .NET para control de dispositivos inteligentes y hogares inteligentes. Se utilizó C# para backend, Angular para frontend, y una base de datos SQL Server. Se probó con Postman y se incluyeron GitHub Actions de Build, Test y Static Code Analysis para verificar calidad de código.
